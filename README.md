# 稳序 · 定投工作台

一个无后端、无第三方依赖的本地优先定投记录与测算工具。支持美元和人民币两套计划，在浏览器中记录实际成交、更新持仓价格，并完成收益与执行纪律测算。

## 功能

- **投资总览**：买入成本、净投入、持仓市值、累计收益和 XIRR。
- **交易记录**：买入、卖出、分红／利息，支持编辑、删除和自定义标的。
- **计划进度**：分别跟踪基础定投、回撤储备和永久短债预算。
- **收益情景**：按初始投入、每月投入、期限和年化假设测算终值。
- **回撤加仓**：按参考高点计算多档触发点位和对应预算。
- **再平衡**：计算恢复目标权益比例所需买入或卖出的金额。
- **数据备份**：导出／导入完整 JSON，或导出当前计划的交易 CSV。

## 本地启动

需要 Node.js 18 或更高版本，无需安装依赖。

```bash
npm run dev
```

默认访问：`http://127.0.0.1:7100/`。

如需指定监听地址或端口：

```bash
npm run dev -- --host 0.0.0.0 --port 7100
```

也可以使用任意静态文件服务器托管本目录；应用运行不依赖 `server.mjs` 的服务端逻辑。

## 测试

```bash
npm test
```

测试覆盖定投终值、XIRR、持仓收益、回撤档位和再平衡计算。

## 数据与隐私

- 所有交易、价格和设置仅保存在当前浏览器的 `localStorage`，不会主动上传到服务器。
- 不同设备、浏览器和线上／本地地址的数据互不同步。
- 清除浏览器数据前，请先点击页面顶部的「备份」导出 JSON；换设备时使用「恢复」导入。
- 仓库中的默认预算和测算金额均为**通用示例**，不是实际资产数据。导入个人备份后，请勿把备份文件提交到仓库或发送到公开环境。
- 静态托管只提供页面文件，不提供账号、访问密码、云端同步或自动行情功能。公开网址不应被视为私密空间。

## 计算口径

- 卖出按移动平均成本法减少剩余成本。
- XIRR 使用实际现金流日期；持仓价格需要手动更新。
- 收益情景假设月末投入、按月复利，未计费用、税、汇率和实际成交时点差异。
- 回撤触发只代表达到既定条件，不代表市场见底。
- 所有测算仅供记录和规划，不构成收益承诺或投资建议。
